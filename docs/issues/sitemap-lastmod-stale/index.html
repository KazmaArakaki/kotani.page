ISSUE / 公開中の情報の誤り

sitemap.xml の lastmod が 2021-11-15 のまま

優先度 低 未対応

概要

sitemap.xml の <lastmod> が 2021-11-15 で止まっている。

ページを更新しても日付が変わらないので、検索エンジンが更新に気づくのが遅れる可能性がある。

先送りにした理由

1ページだけのサイトなので、実害は小さい。移行と内容の修正を混ぜない方針でもある。

優先度

低 実害がほぼない。ほかの対応のついでに片付ける。

対応の進め方

  1. 内容を直したとき（ほかの課題の対応時）に、あわせて日付を更新する
  2. 更新を忘れないよう、開発規約の「ページを更新したら」の手順に入れる
