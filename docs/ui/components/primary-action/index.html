電話ボタン

画面下に常に浮いている「お気軽にお問合せください」のボタン。押すと tel:+81722375695 で電話をかける。

  • 押した時点のスクロール率（0〜100）を、Google アナリティクスの tel_action イベントとして送っている。
  • env(safe-area-inset-bottom) で、iPhone のホームバーに重ならないようにしている。
  • 404 ページの「トップページへ戻る」ボタンは、この見た目を流用する。

使われている画面：トップページ

状態ごとの見た目

見本は旧テンプレートのマークアップと CSS をそのまま使って描画している。

通常

状態はこの1つだけ。ホバーや押下時の見た目の変化はない。
