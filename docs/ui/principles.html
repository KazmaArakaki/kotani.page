UI の基本方針

kotani.page の見た目は、2021年に作られたトップページの CSS がすべてである。 新しい画面（今回は 404 ページ）は、その値を流用して、同じサイトの一部に見えるようにする。

白地に墨色の文字、アクセントは桃色の1色だけ。

書体

小谷はり灸所

古来中国から伝承された本格的な鍼灸治療で、患者様の身体の状態を整えることが私の最大の喜びです。

Shippori Mincho B1 の 400、600、800 の3つだけ。見出しも本文も明朝で揃える。

形と動き

  • ヘッダーは高さ 52px で画面上部に固定。院名は 20px、太さ 800、字間 4px。
  • ボタンは角丸 8px、上下の余白 12px、マテリアル風の3重の影。
  • ページを開くと、全体が3秒かけてふわっと現れる（fade-in 3s）。
  • スマートフォンを先に考える。幅 480px で切り替わる箇所がある。
  • 電話ボタンは画面下に常に固定する。どこまで読んでも、すぐ電話をかけられる。

新しい画面を作るとき

  • 上の色と書体以外を使わない。404 ページの淡い桃色 #f7d3df は、アクセント色を白で薄めた補助色として例外的に足した。
  • 主な行動は、電話ボタンと同じ形のボタン1つにする。
  • 動きを足すときは prefers-reduced-motion で止められるようにする。
