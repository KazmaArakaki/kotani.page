用語集

院の方と開発者のあいだで、同じ言葉を同じ意味で使うための一覧。

小谷はり灸所 こたにはりきゅうしょ

大阪府堺市東区大美野で、自宅に併設して開業している鍼灸院。kotani.page はこの院のホームページである。脈診と舌診にもとづく、中国伝統の鍼灸治療と推拿を行う。

用例

開発者
「ページ内では「当院」と「小谷はり灸所」のどちらで呼ぶのがいいですか？」
院
「見出しは「小谷はり灸所」、文章の中は「当院」でお願いします。」

関連する用語：けんこかわら版、トップページ配信

関連する機能：トップページ配信

けんこかわら版 けんこかわらばん

院が発行していた健康情報の紙面。2018〜2020年の8号ぶんが PDF で公開されていて、トップページの最後の節から表紙画像とリンクで辿れる。表記はひらがなの「けんこ」で、「けんこう」ではない。

用例

開発者
「けんこかわら版の PDF は、新しいサイトにも同じ URL で置きます。」
院
「待合室で配ったものを後から見たいと言われることがあるので、助かります。」

関連する用語：小谷はり灸所、旧サイト

関連する機能：トップページ配信

トップページ配信 とっぷぺーじはいしん

kotani.page のただ一つの機能。トップページと、それが参照する画像と PDF、検索エンジン向けのファイル、ヘルスチェックを返す。

用例

開発者
「このサイトでやることは、トップページを返すことだけです。お問い合わせは電話だけですよね？」
院
「はい。予約も電話で受けています。」

関連する用語：Static Assets、ヘルスチェック

関連する機能：トップページ配信

旧サイト きゅうさいと

移行前の kotani.page。PHP 8.0 と CakePHP で動き、MySQL を使っていた。ソースは移行中 kotani.page.org/ に参照用として置いていたが、移行後に削除した。対になる語は「新サイト」。

用例

開発者
「切り替えてから2週間ほどは、旧サイトのサーバーを止めずに残しておきます。」
院
「何かあったら、すぐ元に戻せるということですね。」

関連する用語：新サイト、意図した差分、不正アクセスブロック

関連する機能：PHP から Workers へ移行

新サイト しんさいと

移行後の kotani.page。Cloudflare Workers の Static Assets で、public/ の静的ファイルを配信する。サーバーも DB も持たない。

用例

開発者
「新サイトは見た目も文章も今と同じです。変わるのは裏側だけです。」
院
「では、お客さんから見て何か変わることはないんですね。」

関連する用語：旧サイト、Static Assets

関連する機能：トップページ配信

意図した差分 いとしたさぶん

旧サイトと新サイトで挙動が違うが、そうなってよいと合意したもの。移行の確認では、これ以外の差分を誤りとして扱う。今回は、存在しない URL の扱い、x-powered-by ヘッダー、不正アクセスブロックの3つ。

用例

開発者
「存在しないページを開いたときだけ、今と違う画面になります。これは意図した差分として記録しておきます。」
院
「トップに戻るボタンがあるなら、困る人はいなさそうですね。」

関連する用語：旧サイト、新サイト

関連する機能：PHP から Workers へ移行

ヘルスチェック へるすちぇっく

サイトが生きているかを外から確かめるための URL /healthcheck。200 と本文 OK を返す。Google Apps Script の定期実行が叩いていて、失敗すると気づける。新サイトでは静的ファイルとして置き、_headers で応答ヘッダーを旧サイトと揃えている。

用例

開発者
「サイトが落ちていないかは、毎日自動で確かめています。新しいサイトでもその仕組みはそのまま使えます。」
院
「見に行かなくても、落ちたら教えてもらえるんですね。」

関連する用語：トップページ配信、workers.dev プレビュー

関連する機能：トップページ配信

構造化データ（JSON-LD） こうぞうかでーた

ページの <head> に置く、検索エンジン向けの院の情報（住所、緯度経度、診療時間、料金、電話番号）。Google の検索結果やマップの表示に使われる。人の目には見えないので、本文と食い違っていても気づきにくい。

用例

開発者
「検索結果に出る診療時間で、木曜日が営業になっているかもしれません。」
院
「木曜はお休みです。間違えて来られたら困るので、早めに直してください。」

関連する用語：トップページ配信

関連する機能：課題：JSON-LD で木曜が営業日

Static Assets すたてぃっくあせっつ

Cloudflare Workers の機能の一つ。指定したディレクトリのファイルを、そのまま配信する。wrangler.jsonc の assets に書くだけで使え、スクリプトがなくても動く。

用例

開発者
「新しいサイトは、ファイルを置いておくと Cloudflare がそのまま配ってくれる仕組みにします。」
院
「サーバーの更新みたいな作業は、なくなるんですか？」
開発者
「なくなります。」

関連する用語：新サイト、workers.dev プレビュー、Custom Domain

関連する機能：トップページ配信

workers.dev プレビュー わーかーずどっとでぶぷれびゅー

Worker をデプロイすると自動で付く kotani-page.<アカウント>.workers.dev の URL。本番ドメインを付け替える前に、新サイトを本番と同じ環境で確かめるために使う。kotani.page では、routes を足した切り替え以降は無効（404）になっている。

用例

開発者
「本番を切り替える前に、別の URL で新しいサイトをお見せします。今のサイトと見比べてください。」
院
「地図が出ていないようですけど？」
開発者
「地図は本番の URL でしか表示されない設定なので、切り替え後に出ます。」

関連する用語：Custom Domain、Static Assets

関連する機能：PHP から Workers へ移行

Custom Domain かすたむどめいん

Worker に独自ドメイン（ここでは kotani.page）を割り当てる Cloudflare の機能。DNS レコードと証明書を Cloudflare が用意する。wrangler.jsonc の routes に custom_domain: true で書く。

用例

開発者
「確認が終わったら、kotani.page のアドレスを新しいサイトに向けます。数分で切り替わります。」
院
「お客さんが見るアドレスは変わらないんですね。」

関連する用語：workers.dev プレビュー、Static Assets

関連する機能：PHP から Workers へ移行

不正アクセスブロック ふせいあくせすぶろっく

旧サイトにあった仕組み。存在しない URL へのアクセスを IP アドレスごとに MySQL の invalid_access_logs に記録し、回数に応じてしばらくアクセスを拒否していた。新サイトには移行しない。

用例

開発者
「今のサイトには、怪しいアクセスを締め出す仕組みがあります。新しいサイトは中身が静的なファイルだけなので、締め出さなくても壊される場所がありません。」
院
「それなら、なくしても大丈夫そうですね。」

関連する用語：旧サイト

関連する機能：課題：旧サーバーの停止
