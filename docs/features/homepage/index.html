トップページ配信

小谷はり灸所を探している人が、場所と診療時間を確かめ、電話をかけるまでの1枚。 kotani.page が持つ機能はこれだけである。

ページの中身は2021年秋に作られてから、ほとんど変わっていない。 変わったのは載せている土台のほうで、2026年10月に PHP から Cloudflare Workers の Static Assets へ移すことにした。 移行の詳細はセッションのドキュメントにある。

配信の仕組み

Worker はスクリプトを持たず、public/ のファイルを返すだけである。 リクエストに一致するファイルがなければ、404.html を 404 で返す。

ページの構成

上から順に、院名、導入文、当院の特色、診療科目、メディア紹介、アクセス、診療時間、診療費、けんこかわら版と続き、最後にフッターと地図がある。 画面の下には電話ボタンが常に浮いていて、どこまで読んだ時点でも電話をかけられる。

ページの <head> には構造化データ（JSON-LD）があり、検索エンジンに住所や診療時間を伝えている。 診療時間は本文と同じく月・火・水・金の午前と午後。以前は木曜日が営業日として入っている誤りがあり、2026-10-22 に直した。
